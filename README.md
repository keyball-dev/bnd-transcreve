# BND Transcreve

PWA que transcreve áudios (WhatsApp ou qualquer áudio) 100% no celular, com Whisper rodando no navegador (transformers.js). Sem backend, sem chave de API.

Site: https://keyball-dev.github.io/bnd-transcreve/

Os ícones PNG ficam em base64 (`*.png.b64`) no main e o workflow gera o branch `gh-pages`.
